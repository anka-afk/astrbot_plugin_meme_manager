操作日志

图床配置教程

Cloudflare R2

  1. 创建存储桶。登录 Cloudflare 控制台，在 R2 对象存储中创建一个桶，记下桶名称和 Account ID。
  2. 创建 R2 API 凭证。为这个桶授予对象读写权限，保存生成的 Access Key ID 和 Secret Access Key。
  3. 填写设置。关闭教程，在“图床服务”选择 Cloudflare R2，将上述四项分别填入账号 ID、访问密钥 ID、访问密钥和存储桶名称。
  4. 按需填写公开地址。需要公开外链时，在桶设置中绑定自定义域名，或复制控制台提供的公共开发地址。将完整的 HTTPS 地址填入“自定义 CDN 域名”；不要填写 S3 API 地址。r2.dev 开发地址有访问限流。

仅做同步可以不填写公开地址。凭证用于插件访问存储桶，公开地址用于访问图片，两者用途不同。

WebDAV

  1. 准备连接信息。在 NAS 或云存储服务中启用 WebDAV，获取 WebDAV 地址、用户名和密码或应用密码。填写 WebDAV 接口地址，不是网页登录地址。
  2. 填写设置。在“图床服务”选择 WebDAV，填写根地址和账号凭证。远端目录可填 memes，插件会在该目录保存同步图片。
  3. 检查连接选项。保持 SSL 证书校验开启；连接较慢时可适当增加请求超时时间。服务端账号需有远端目录的读取、写入权限，使用覆盖同步时还需删除权限。
  4. 按需填写公开地址。只有服务提供无需登录的图片外链时才填写公开访问根地址。它应对应远端目录，例如 https://cdn.example.com/memes；不提供外链也可以用于同步。

不同服务的 WebDAV 路径不同，请从服务端的 WebDAV 设置或帮助文档复制。出现 401/403 时检查应用密码与目录权限，出现 404 时检查根地址。

StarDots

  1. 创建空间。登录 StarDots 控制台，创建用于保存表情图片的空间，并记下空间名称。
  2. 获取凭证。在控制台设置的 API 管理区域获取 Key 和 Secret。
  3. 填写设置。在“图床服务”选择 StarDots，将 Key、Secret 和空间名称填入对应配置项。

同步前请在服务商控制台确认可用容量和 API 配额；套餐限制以服务商当前说明为准。
