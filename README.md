**v5.0.2 重制了图床同步。** 首次升级后，缺少内容校验记录的同名图片会显示“待确认”，普通同步会保留这些图片。请先检查差异，再在管理页的“高级同步”中选择覆盖方向；覆盖会删除目标端多出的图片，执行前会显示预计数量。已有图片和旧记录不会自动搬迁或删除。

**尚未应用 v5.0.1 新版提示词的用户，请按需重置默认模板。** 升级并重载插件后，进入 **设置中心 → 提示词模板 → 恢复默认模板 → 保存并应用**，载入新版前缀、后缀及附加模板。已有自定义内容请先复制备份，再按需合并回新版模板。

从 v4.x 升级的用户：v5.0.0 起旧版平铺配置和配置别名不再读取或迁移，加载时会清除废弃字段。升级前请备份插件配置及表情包数据，升级后检查设置并重新填写仅存在于旧配置中的选项；当前分组结构中的有效设置会保留。

## 🛠️ 第一次使用

1. 安装插件后，进入 AstrBot WebUI → 插件页面 → **表情包管理器**。
2. 打开**资源广场**，下载一个官方或社区表情包；也可以使用 `/表情管理 恢复默认表情包` 安装官方包。
3. 进入**设置中心 → 使用规则**，将下载的包设为默认，或绑定到指定会话、人格，然后保存规则。
4. 开始聊天。插件会自动提供当前表情包的分类提示，无需修改人格；有合适的表情时，模型可以配合文字发送，也可以只发表情。

首次使用没有内置图片，需要先安装表情包。管理页的选包用于浏览和编辑，聊天实际使用哪个包由使用规则决定。

## ❓ 常见问题

**必须配置图床吗？** 不需要。图床用于云端同步，本地管理与表情发送可独立使用。

**下载了新包，为什么聊天还用原来的？** 请在设置中心保存使用规则。下载或切换管理页的表情包，不会自动修改聊天选包规则。

**可以流式回复吗？** 可以。经过 AstrBot 流式消息管线的标签会在发送前解析，有歧义的片段会暂时缓冲，图片在回复结束后发送。

**必须进行语义化吗？** 不需要。普通分类模式即可使用；希望按图片描述检索时，再配置语义化。

**不使用 WebUI 能管理吗？** 可以使用下方指令。目录结构、插件联动接口与开发方法见 [开发指南](DEVELOPMENT.md)。

### 表情包管理

按分类预览图片，上传、删除、拖拽移动或批量整理表情，编辑分类描述，并切换不同表情包进行管理。

![表情包管理](.github/img/表情包管理.png)

### 语义表情包

普通模式按分类选择表情；语义模式会先为图片生成描述和检索向量，再根据对话寻找更贴切的图片。使用前需在设置中心配置图片描述模型与向量模型，并在“语义化”页面完成处理。生成描述和向量会调用对应模型，费用取决于所用服务。

语义化页面可以查看处理进度、继续任务和重试失败图片。自动收集的图片统一在表情包管理页审核接收后，再按需生成语义索引。

![语义表情包](.github/img/语义表情包页面.png)

### 设置中心

设置按用途分类：**使用规则、表情发送、语义与模型、自动收集、存储与下载、提示词模板、标签与匹配、导入与备份**。可搜索配置名称，修改参数后点击“保存并应用”；使用规则单独保存。

- **使用规则**：从上到下匹配会话或人格，没有匹配项时使用默认表情包。
- **提示词模板**：分类提示词的前缀定义能力与发送格式，后缀规定内部资料边界和图片理解；分类示例与回复形式示例各自独立开启。表情回复数量提示控制频率和数量偏好，默认关闭、可编辑，覆盖分类、语义和情感辅助选图，与“表情发送”中的硬上限独立。硬上限仅在发送阶段兜底截断。
- **存储与下载**：配置可选的云端同步。在当前图床的配置区点击“图床配置教程”，弹窗会展示该服务的配置步骤。
- **导入与备份**：导入、导出表情包，或制作全量备份用于迁移。

![设置中心](.github/img/表情包设置中心.png)

## 🤖 自动收集表情包

在**设置中心 → 自动收集**开启，并选择支持图片输入的视觉模型。插件会识别收到的图片，从目标表情包的现有分类中选择合适的分类，并进行去重。可以限制收集来源、抽样概率、识别间隔和每日识图次数。

自动收集默认关闭，识图会调用模型；**人工审核表情包默认开启**，普通模式和语义模式都先进入待审核列表，不会直接用于回复。

1. 进入**表情包管理**，切换到收集目标包。
2. 有待审核图片时，选包框右侧显示**待审核表情**按钮，点击查看图片、建议分类和两项置信度。
3. 默认按分类置信度从高到低排列，低把握度排在后面；可筛选分类、调整排序和修改接收分类，然后接收选中的图片。
4. 不需要的图片可以丢弃；勾选“不再收集”后，相同内容不会再次进入该包的候选列表。近似重复只作提示，不会自动丢弃不同文字或不同动画的图片。

关闭人工审核后，新收集的图片自动入包，已有待审核图片仍需处理。**无论审核开关是否开启，语义索引都由用户手动生成**。符合当前语义描述标准且接收分类未改变的收集结果可直接复用描述；旧结果或改过分类的结果保留为草稿，语义化时重新生成。

每个包的待审核容量默认 200 张，达到上限后暂停提交新候选，不会自动清理已收集图片。精确去重会检查图库和待处理图片，视觉近似比较仅用于静态图片提示。

## 📝 使用指令

当前大部分功能都可以通过 AstrBot WebUI 管理界面操作，无需使用指令。以下为指令列表，供 CLI 用户参考：

| 指令                                   | 描述                                                |
| -------------------------------------- | --------------------------------------------------- |
| `/表情管理 查看图库`                   | 📚 列出所有可用表情类别                             |
| `/表情管理 添加分类 [类别名称] [描述]` | ➕ 创建新的表情包分类，可只输入名称后按提示补充描述 |
| `/表情管理 添加表情 [类别]`            | ➕ 通过聊天上传表情到指定类别                       |
| `/表情管理 恢复默认表情包`             | ♻️ 从官方仓库一键安装首个官方表情包并设为默认       |
| `/表情管理 清空指定类型 [类别]`        | ⚠️ 清空指定类别中的表情包，保留类型本身             |
| `/表情管理 清空全部`                   | ⚠️ 清空全部表情包，保留所有类型和描述配置           |
| `/表情管理 删除类型本身 [类别]`        | ⚠️ 删除指定类型及其描述配置                         |
| `/表情管理 同步状态`                   | 🔄 检查同步状态                                     |
| `/表情管理 同步到云端`                 | ☁️ 将本地表情同步到云端                             |
| `/表情管理 从云端同步`                 | ⬇️ 从云端同步表情到本地                             |
| `/表情管理 覆盖到云端`                 | ⚠️ 让云端与本地完全一致                             |
| `/表情管理 从云端覆盖`                 | ⚠️ 让本地与云端完全一致                             |

## 📜 更新日志

当前版本：v5.0.3

- ⚡ **语义页面减负**：打开或切换语义化页面不再自动扫描建档，也不会为校验完成状态而逐张读取图片计算 SHA-256；图包列表仅统计文件数量并读取已有进度。

- 🛡️ **保留检索校验**：页面展示已保存的完成状态，实际语义检索仍严格校验图片内容，避免使用被替换图片的旧语义记录。
